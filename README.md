# Task-03: Text Generation with Markov Chains

This project was completed as part of my Generative AI Internship at Prodigy InfoTech.

## Objective

Implement a simple text generation algorithm using Markov Chains.

The model learns the probability of a character or word based on the previous character(s) or word(s) and generates new text using those learned probabilities.

## Technologies Used

- Python
- Markov Chains
- Probability
- Natural Language Processing

## How It Works

1. Load the training text.
2. Build a Markov Chain from the text.
3. Calculate transition probabilities.
4. Select the next character/word based on the learned probabilities.
5. Generate new text.
